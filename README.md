# Aplikasi Catatan Tugas Mahasiswa

Aplikasi web sederhana menggunakan HTML, CSS, dan JavaScript murni untuk mencatat daftar tugas-tugas kuliah beserta tenggat waktunya.

## Cara Menjalankan
1. Ekstrak file ZIP ini ke dalam sebuah folder di laptop/komputer kamu.
2. Buka file `index.html` menggunakan browser (seperti Google Chrome, Microsoft Edge, atau Firefox).
3. Aplikasi sudah siap digunakan! Tambahkan tugas, mata kuliah, dan tenggat waktu.

## Fitur
- **Tambah Tugas**: Masukkan nama tugas, mata kuliah, dan deadline.
- **Tandai Selesai**: Klik tombol centang hijau jika tugas sudah dikerjakan.
- **Hapus Tugas**: Klik tombol X merah untuk menghapus tugas.
- **Penyimpanan Lokal**: Data otomatis tersimpan di Local Storage browser, sehingga tidak akan hilang walaupun browser ditutup (kecuali riwayat cache dibersihkan).
